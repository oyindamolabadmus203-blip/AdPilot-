---
name: Netlify initial mode
description: AdPilot's first Netlify deployment should be a public static landing page.
---

For the initial Netlify deployment, publish only the public landing page without sign-in or API calls. Keep the existing full Replit app and API source code so the backend can be connected later.

**Why:** the user chose a landing-page-only Netlify view and said APIs should be connected later.

**How to apply:** Keep static mode scoped to Netlify's build configuration; do not disable the full app or remove its API code.
